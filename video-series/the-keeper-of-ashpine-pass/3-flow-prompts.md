# The Keeper of Ashpine Pass — Stage 3: Google Flow Video Prompts (v2)

**8 clips × 8 s · 16:9 · Veo in Google Flow**

## What changed in v2 (lessons from the first clip-1 test)
| Problem seen in the test | Fix used in every prompt |
|---|---|
| The prompt was blocked by policy | No banknotes (a closed leather money pouch instead), no guns (a rope and capture net instead), no alcohol (coffee mugs), "finds" instead of "brings me" |
| Walt grew a full beard | Locked line now says "clean-shaven chin and upper lip with no beard or moustache", plus "no beard on Walt" in the negatives |
| A hidden cut halfway through; Walt jumped position | Every prompt opens with **ONE CONTINUOUS SHOT, NO CUTS** and a locked-off or very slow camera |
| The door left the frame and came back different (two doors) | The position of every important object is stated exactly, and it **stays in frame the whole clip**; "only ONE door" |
| The first 2.5 s were an empty room | The **start state** is described first; the main action happens in the first second |
| Too much action for 8 s | One main action per clip |
| Wrong people (3 lumberjacks, Doreen sitting) | Exact count and pose for every person, plus "no extra people" |

## How to make each clip
1. Attach the **3 Ingredients** listed (Characters + Uploads).
2. **Start image first:**
   - Clips **1, 5, 6** start in a new place, so make the **START IMAGE** with the prompt given, check it, then animate it.
   - Clips **2, 3, 4, 7, 8** continue directly, so use the **last frame of the previous clip** as the start image (*Frames to Video*).
3. Check the start image before approving the video: right people, right faces (Walt with **no beard**), right positions, one door.
4. Paste the **VIDEO PROMPT**. Use the **Fast** or **Quality** Veo model for final takes (Lite for tests only).
5. Keep the best take. If the clip is longer than 8 s, trim it in editing.

## Quick fixes if a take goes wrong

| Problem | Fix |
|---|---|
| Blocked by policy | Remove any money, weapons, alcohol, blood or "attack" words; describe intention through faces and props instead |
| Walt has a beard | Regenerate the start image first; make sure his Character info says "no beard, no moustache" |
| A cut or jump in the middle | Make sure the prompt starts with "ONE CONTINUOUS SHOT, NO CUTS" and the camera is static; remove one action |
| An object moves or duplicates | State its exact position ("in the right wall", "on the left") and add "stays in frame the whole time" |
| A face looks different | Re-attach the character; use the previous clip's last frame as the start image |
| Skin looks plastic | Add: "unretouched skin, visible pores, natural redness and wrinkles" |
| Creature looks cartoonish | Add: "real wildlife documentary footage, real animal anatomy" |
